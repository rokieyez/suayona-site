# 통째로 내려받기 (백업)

사진·영상·아이 목소리와 글·작품·일정·시간표를 전부 이 컴퓨터로 가져옵니다.

```
node tools/backup.mjs
```

받는 곳을 정하고 싶으면 뒤에 적습니다:

```
node tools/backup.mjs /Volumes/외장하드/수아랑연아랑-백업
```

안 적으면 `~/수아랑연아랑-백업` 에 쌓입니다.

## 무엇이 받아지나

```
수아랑연아랑-백업/
  사진/
    event-images/     작품 사진, 일기 사진, 아이 목소리
    gallery-uploads/  이벤트 갤러리 사진·영상
  기록/
    2026-08-31/       그날의 글·작품·일정·시간표 (JSON)
    2026-09-30/       다음 달에 받으면 이렇게 날짜별로 쌓입니다
  이게 무엇인가요.txt
```

사진은 **한 벌만** 유지하고 새로 올린 것만 더합니다. 기록은 작아서 받을 때마다
날짜 폴더로 따로 쌓아 둡니다 — 예전에 뭐라고 적었는지 되돌아볼 수 있게요.

## 알아둘 것

- **비밀번호는 어디에도 저장하지 않습니다.** 물어보기만 하고, 화면에도 안 보이고,
  받은 파일 어디에도 남지 않습니다. 돌릴 때마다 다시 물어봅니다.
- **두 번째부터는 금방 끝납니다.** 이미 받아 둔 사진은 건너뜁니다.
- **다 받았는지 확인하고 끝냅니다.** 글에 적힌 사진 주소를 하나씩 대조해서, 빠진 게
  있으면 몇 개인지 알려 줍니다. 한 번 더 돌리면 빠진 것만 받습니다.
- **받다 만 파일은 남지 않습니다.** 내려받는 중에는 임시 이름으로 두었다가 다 받은
  뒤에야 제자리에 놓습니다. 중간에 끊겨도 반쪽짜리 사진이 생기지 않습니다.
- 표를 하나라도 다 읽지 못하면 **그 자리에서 멈춥니다.** 반만 받아 놓고 다 받은 척하면
  백업이 아니라 착각이 되기 때문입니다.

## 안 받아지는 것

**로그인 계정 자체(이메일·비밀번호)** 는 어떤 방법으로도 내려받을 수 없습니다.
홈페이지를 처음부터 다시 세우게 되면 계정은 새로 만들고, `profiles.json` 을 보고
누가 어떤 역할이었는지 다시 이어 주면 됩니다.

## 주마다 알아서 받게 하기

이미 걸려 있습니다. **일요일 밤 9시**에 맥이 알아서 받습니다.
맥이 꺼져 있었으면 다음에 켰을 때 한 번 돕니다.

### 처음 한 번만 (직접)

로그인 정보를 키체인에 넣어 둡니다. 비밀번호는 물어보기만 하고 화면에 안 보입니다.

```bash
security add-generic-password -a "이메일주소" -s suayona-backup -w
```

그다음 아래를 한 번 손으로 돌려 주세요. 키체인이 "쓰게 해줄까요?" 하고 물으면
**항상 허용**을 누릅니다. 이걸 안 해두면 밤에 혼자 돌 때 그 창에서 멈춥니다.

```bash
tools/backup-weekly.sh
```

이메일은 여기 적어 두지 않고 키체인의 '계정' 칸에서 꺼내 씁니다 —
이 폴더는 홈페이지와 함께 인터넷에 올라가는 곳이라서요.

### 잘 되고 있나 보기

```bash
tail -40 ~/Library/Logs/suayona-backup.log
```

무슨 일이 있었는지 날짜와 함께 남습니다. 실패했으면 왜 실패했는지도 적힙니다.

### 지금 당장 한 번 돌려보기

```bash
launchctl kickstart -p gui/$UID/com.suayona.backup
```

### 끄기 / 다시 켜기

```bash
launchctl bootout gui/$UID/com.suayona.backup                              # 끄기
launchctl bootstrap gui/$UID ~/Library/LaunchAgents/com.suayona.backup.plist   # 켜기
```

**홈페이지 폴더를 옮기면 끊깁니다.** 옮기셨다면 위의 끄기/켜기를 다시 하시고,
`~/Library/LaunchAgents/com.suayona.backup.plist` 안의 경로도 새 자리로 고쳐야 합니다.
(그냥 두면 기록에 "백업 도구가 없습니다" 라고 남습니다 — 조용히 안 되는 일은 없습니다.)

## 이 폴더는 홈페이지가 아닙니다

`tools/` 안의 것은 집에서 돌리는 도구입니다. 홈페이지 화면과는 상관이 없습니다.
