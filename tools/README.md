# 통째로 내려받기 (백업)

사진·영상·아이 목소리와 글·작품·일정·시간표를 전부 이 컴퓨터로 가져옵니다.

```
node tools/backup.mjs
```

받는 곳을 정하고 싶으면 뒤에 적습니다:

```
node tools/backup.mjs /Volumes/외장하드/수아랑연아랑-백업
```

안 적으면 `~/수아랑연아랑-백업` 에 쌓입니다.

## 무엇이 받아지나

```
수아랑연아랑-백업/
  사진/
    event-images/     작품 사진, 일기 사진, 아이 목소리
    gallery-uploads/  이벤트 갤러리 사진·영상
  기록/
    2026-08-31/       그날의 글·작품·일정·시간표 (JSON)
    2026-09-30/       다음 달에 받으면 이렇게 날짜별로 쌓입니다
  이게 무엇인가요.txt
```

사진은 **한 벌만** 유지하고 새로 올린 것만 더합니다. 기록은 작아서 받을 때마다
날짜 폴더로 따로 쌓아 둡니다 — 예전에 뭐라고 적었는지 되돌아볼 수 있게요.

## 알아둘 것

- **비밀번호는 어디에도 저장하지 않습니다.** 물어보기만 하고, 화면에도 안 보이고,
  받은 파일 어디에도 남지 않습니다. 돌릴 때마다 다시 물어봅니다.
- **두 번째부터는 금방 끝납니다.** 이미 받아 둔 사진은 건너뜁니다.
- **다 받았는지 확인하고 끝냅니다.** 글에 적힌 사진 주소를 하나씩 대조해서, 빠진 게
  있으면 몇 개인지 알려 줍니다. 한 번 더 돌리면 빠진 것만 받습니다.
- **받다 만 파일은 남지 않습니다.** 내려받는 중에는 임시 이름으로 두었다가 다 받은
  뒤에야 제자리에 놓습니다. 중간에 끊겨도 반쪽짜리 사진이 생기지 않습니다.
- 표를 하나라도 다 읽지 못하면 **그 자리에서 멈춥니다.** 반만 받아 놓고 다 받은 척하면
  백업이 아니라 착각이 되기 때문입니다.

## 안 받아지는 것

**로그인 계정 자체(이메일·비밀번호)** 는 어떤 방법으로도 내려받을 수 없습니다.
홈페이지를 처음부터 다시 세우게 되면 계정은 새로 만들고, `profiles.json` 을 보고
누가 어떤 역할이었는지 다시 이어 주면 됩니다.

## 자동으로 돌리고 싶다면

`SUAYONA_EMAIL` 과 `SUAYONA_PASSWORD` 가 있으면 아무것도 묻지 않습니다.
다만 비밀번호를 파일에 적어 두는 건 권하지 않습니다. 맥의 키체인에서 꺼내 쓰는 편이
안전합니다:

```bash
# 한 번만: 키체인에 넣어 두기
security add-generic-password -a suayona -s suayona-backup -w

# 그 뒤로는 이렇게
SUAYONA_EMAIL=(이메일) \
SUAYONA_PASSWORD="$(security find-generic-password -a suayona -s suayona-backup -w)" \
node tools/backup.mjs
```

## 이 폴더는 홈페이지가 아닙니다

`tools/` 안의 것은 집에서 돌리는 도구입니다. 홈페이지 화면과는 상관이 없습니다.
