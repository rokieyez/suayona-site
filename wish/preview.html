어떻게 만들 생각인지

한 곳의 일생을 한 자리에서 따라갑니다. 가고 싶다 → 계획 중 → 다녀옴 → 별점과 한마디. 지금은 다녀온 곳만 이벤트에 쌓이고, 가고 싶은 곳은 어디에도 남지 않습니다. 그 앞자리와 뒷자리를 같은 표에 두는 것이 이 기능입니다.

별은 하나만 씁니다

이 쪽은 혼자 관리하는 자리입니다. 별은 다섯 점 하나로 매기고, 다녀온 곳에만 뜹니다. 가기 전에는 「얼마나 가고 싶은지」를 작은 회색 별로 따로 씁니다 — 기대와 평가는 다른 것이라, 다녀온 뒤에 둘을 견주어 보는 재미가 있습니다.

화면은 넷이면 충분합니다

화면하는 일
지도 띠안 간 곳은 점선 핀에 번호, 다녀온 곳은 채운 핀에 별점. 지도만 봐도 갈린다
카드 목록누르면 펼쳐져 메모·링크·별점이 보인다. 별은 그 자리에서 바로 누른다
돌아보기별이 높은 차례로 다섯 곳. 어디가 좋았는지 한눈에 남는다
넣기 폼장소를 찾아 고르면 좌표·주소가 자동으로 채워진다. 관리자로 들어왔을 때만 보인다

표 하나면 됩니다

create table places (
  id          bigserial primary key,
  name        text not null,
  category    text,                   -- 놀이 / 먹거리 / 자연 / 체험 / 숙소
  lat         double precision,       -- 카카오 장소 찾기가 채운다
  lng         double precision,
  address     text,
  memo        text,
  links       text[],
  photo_url   text, thumb_url text,
  season      text,                   -- 봄 / 여름 / 가을 / 겨울 / 아무때나
  hope        int  default 0,         -- 가기 전 기대 (0~3)
  status      text default 'want',    -- want / planned / done
  visited_on  date,                   -- 다녀온 날
  event_id    text,                   -- 그때 만든 이벤트 slug
  stars       int check (stars between 1 and 5),   -- 다녀온 뒤 별
  review      text,                   -- 다녀온 뒤 한마디
  again       boolean,                -- 또 갈까
  created_at  timestamptz default now()
);

-- 손님은 보기만, 쓰기는 관리자만 (다른 표와 같은 규칙)
alter table places enable row level security;
create policy "누구나 읽기"  on places for select using (true);
create policy "관리자만 쓰기" on places for all
  using (auth.role() = 'authenticated') with check (auth.role() = 'authenticated');

이어지는 자리

  • 이벤트로 만들기 — 가볼 곳 카드에서 바로 새 이벤트를 엽니다. 이름·좌표·메모가 첫 일정에 들어갑니다.
  • 다녀옴 표시 — 이벤트를 만들면 상태가 저절로 「다녀옴」이 되고, 그날부터 별을 매길 수 있습니다.
  • 이벤트에서 거꾸로 — 이미 있는 이벤트의 장소를 「가본 곳」으로 한 번에 옮겨 담습니다. 지금 이벤트에 찍힌 자리가 28군데라 시작부터 목록이 비어 있지 않습니다.
  • 첫 화면 잇기 — 「다녀온 곳」 지도 옆에 「가볼 곳 N군데 · 별 4.2」를 한 줄 더합니다.
  • 가까운 곳 알림 — 이벤트를 만들 때 그 자리에서 가까운 가볼 곳이 있으면 「여기도 근처예요」로 보여 줍니다.

일부러 안 넣은 것

  • 여러 사람이 매기는 별 — 혼자 관리하는 쪽이라 별은 하나면 됩니다. 사람을 나누면 표가 하나 더 늘고 화면도 복잡해지는데, 얻는 것이 없습니다.
  • 링크 미리보기 자동 만들기 — 서버가 없어 남의 쪽 제목·사진을 대신 받아올 자리가 없습니다. 엣지 함수를 하나 두면 되지만, 그만한 값어치인지 먼저 써 보고 정하는 편이 낫습니다.
  • 지도에서 바로 찍어 넣기 — 손전화에서 정확한 자리를 짚기 어렵습니다. 이름으로 찾는 쪽이 빠릅니다.
